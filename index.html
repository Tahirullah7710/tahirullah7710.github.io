01 / ABOUT

Research at the intersection of AI and software engineering.

I am a doctoral researcher in Software Engineering at the School of Computer Science and Technology, Beijing Institute of Technology. My research focuses on software security, automated software maintenance, and program analysis.

I combine large language models (LLMs), static analysis, repository mining, and graph-guided reasoning to identify silent security patches, classify software weaknesses, and synthesize executable verifiers. My earlier research explored requirements engineering, user-feedback mining, rationale extraction, and applied natural language processing.

I am interested in building reliable, evidence-driven methods that connect AI-assisted reasoning with executable program analysis and practical software engineering workflows.

02 / SELECTED RESEARCH

Research projects

Selected work on intelligent software analysis and security-patch understanding.

01Published · ASE 2025

COMMIT CLASSIFICATION · LLMs

AACC

Augmented Agentic Commit Classification

An LLM-based approach for identifying Null Pointer Exception (NPE) fixing commits. The approach combines context-aware example selection, an augmented knowledge base, agentic prioritization, and iterative refinement to improve commit-level classification.

LLMsCommit ClassificationRepository Mining

Publication: LLM-Based Identification of Null Pointer Exception Patches, IEEE/ACM ASE 2025.

02Under review · FSE 2027

SECURITY PATCH IDENTIFICATION · EXECUTABLE VERIFICATION

WISE-Fix

Weakness-Informed Executable Verification

An LLM-assisted framework that synthesizes executable verifiers offline and applies weakness-informed verification to identify silent security fixes in C/C++ repositories. It aims to move beyond text similarity by checking whether candidate fixes satisfy executable security-relevant properties.

Executable VerificationStatic AnalysisC/C++LLMs

Manuscript submitted to the ACM Foundations of Software Engineering (FSE 2027); under review.

03Under review · IEEE TSE

CWE CLASSIFICATION · GRAPH REASONING

CWEMap

Phase-Aware Evidence Alignment for Fine-Grained CWE Classification

CWEMap represents target and historical security patches across vulnerable-state, repair-transformation, and post-repair phases. Structural Evidence Alignment (SEA) aligns phase-constrained graph evidence; NERP ranks matched evidence by node and edge semantic relevance; and the Hierarchical Taxonomy Reasoner (HTR) supports taxonomy-constrained CWE-path prediction.

Knowledge GraphsSEANERPHTRCWE

Manuscript submitted to IEEE Transactions on Software Engineering (TSE); under review.
