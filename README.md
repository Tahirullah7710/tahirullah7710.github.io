# Tahir Ullah — Academic Portfolio

A responsive, static academic portfolio designed for free hosting with GitHub Pages.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive academic visual design
- `script.js` — mobile navigation and current-year footer

## Publish with GitHub Pages (free)

### Option A — personal website URL
1. Sign in to GitHub and create a **public** repository named exactly:
   `YOUR-GITHUB-USERNAME.github.io`
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. After GitHub Pages finishes deploying, visit:
   `https://YOUR-GITHUB-USERNAME.github.io/`

### Option B — project repository URL
1. Create a public repository, for example `academic-portfolio`.
2. Upload the three website files to its root.
3. In **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`.
4. Your URL will be:
   `https://YOUR-GITHUB-USERNAME.github.io/academic-portfolio/`

## Before publishing — personal checks
- Confirm that **Tahir Ullah** is the exact public name you want. Your LinkedIn display name may differ; keep your public name consistent with your academic publications.
- Confirm the email address in `index.html`.
- Add your Google Scholar, ResearchGate, GitHub, and institutional profile URLs when you have the exact public links. No unverified profile URLs have been fabricated.
- Consider whether you want to publish a phone number. This version intentionally omits it.
- Verify the publication metadata and current manuscript status before launch. WISE-Fix and CWEMap are explicitly marked as under review, not accepted.
- Add a PDF CV link only after placing a public copy of your CV in this repository (for example, `assets/Tahir_Ullah_CV.pdf`) and adding a link to it.

## Editing
Edit the text in `index.html`. Change colors and spacing in `styles.css`. No build tools, frameworks, or paid services are required.

## Notes
- The site uses Google Fonts when internet access is available; system fonts remain as fallbacks.
- GitHub Pages provides a free `github.io` subdomain. A custom domain is optional and is not needed for this site.
