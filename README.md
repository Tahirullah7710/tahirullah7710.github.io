# Tahir Ullah — Academic Portfolio

A responsive, static academic portfolio designed for free hosting with GitHub Pages.

## Preview locally
Open `index.html` in a browser. For a local web server, run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Publish with GitHub Pages (free)
1. Create or sign in to a GitHub account.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload `index.html`, `style.css`, `script.js`, and this README to the repository root.
4. Open **Settings → Pages**. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Your free website address will be `https://YOUR-GITHUB-USERNAME.github.io/`.

GitHub Pages usually publishes within a few minutes. No paid domain or hosting is required.

## Before publishing
- Replace the Google Scholar, ResearchGate, and GitHub placeholder links in `index.html` with the correct profile URLs, or remove those links.
- Confirm the exact wording/status of each manuscript immediately before publication.
- Add DOI and publisher links to each publication where available.
- Optionally add a headshot and a downloadable public CV after reviewing the personal information in the CV. The current website intentionally does not publish your phone number, residential address, date of birth, or passport details.
- Confirm whether the AACC expansion and project description match the final published paper.
- The site labels WISE-Fix and CWEMap as under review, not accepted or published.
